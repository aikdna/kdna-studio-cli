# Current command boundary

Supported commands: `help`, `--help`, `--version`, `session`, `verify`, `read`. Unknown commands, repeated or unknown options fail before opening materials or output. Package exports expose metadata only; the supported executable is the bin. No deep path, alternate checkout, model, remote server or runtime fallback is selected.

`session --out NEW_DIRECTORY` accepts repeated `--text FILE` and `--interview FILE`, `--synthetic-fixture`, and exactly one adoption mode. Human mode uses a controlling terminal or `--human-fd N`. Explicit delegated Agent mode requires both `--agent-adoption-fd N` and `--delegation-record FILE`. N is an integer at least 3. Human and Agent fd options cannot be combined. The delegation file contains only nonempty `coordinate` and `statement`; it is an explicit embedding claim, not an authenticated grant.

The child owns its inherited adoption read endpoint, a TTY, pipe or socket; a regular file cannot stand in for a live reply channel. It cancels and releases only its own endpoint on completion or abandonment. The parent owns its writer. Both Agent JSONL and adoption endpoints must remain healthy; EOF/error before export terminates the workspace and late replies cannot revive it. There is no default timeout or manufactured reply. A slow active reviewer may continue deciding.

Frames are limited to 1 MiB. At most one complete next frame plus a bounded partial frame is held while an operation is pending; excess pipelining rejects `CLI_INPUT_QUEUE_LIMIT`. Each request id is unique; each interpretation names the one live reply ticket. Reuse or another operation during review rejects. Already-completed synchronous export is not undone by a later EOF.

`verify --bundle DIRECTORY` captures actual bytes, admits them with Core, requires the current private completion marker, and delegates evidence verification to Studio. `read --bundle DIRECTORY [--allow-read] [--judgment N] [--budget BYTES]` first admits its formal Read request, then verifies the current bundle, then invokes public Read. Invalid budgets reject before bundle I/O. Invalid Core bytes or evidence prevent later disclosure; a consistent bundle still needs explicit read permission. Catalog ordinal selection is Host navigation; closure and projection remain in Read.

Private bundles contain `asset.kdna`, `creation-evidence.json`, `binding.json`, `verification.json`, and `complete.json`. The latter is `{kind:'private-studio-export-bundle',version:2}`. Output reservation is exclusive, saved bytes are re-captured and passed to Studio `completeSave`, then completion is written last. Existing outputs are never replaced. A partial reservation is removed only by its owning invocation. Persistent import/resume, overwritten outputs, external compiler callbacks, signing services, identity verification and action execution are unsupported.

Stdout is private machine JSON and may contain materials, evidence and disclosed content. Stderr contains prompts/previews or concise errors. Do not publish these streams. Errors do not echo raw frames, source paths, stacks or provider secrets. Exit 0 denotes successful export/verification or ready Read; 2 denotes terminal, transport, operation or filesystem rejection; 3 denotes public admission, evidence or disclosure rejection.

Studio format `kdna.studio-creation-evidence/2` and the exact current graph are required. The CLI does not implement another evidence canonicalizer, component interpreter or legacy branch. Static consistency cannot restore `accepted_with_live_context`: static status retains `creation_accepted:not_evaluated`, `live_context:unavailable`, `identity:not_verified` and `action_authorization:not_evaluated`. Role-specific adoption records do not authenticate a person or Agent.

Before executing dependencies, the Host checks every member, path set, package version, mandatory resolution and unbound optional package against `src/public-bindings.json`. Archive equality is a local content observation; installation approval and process-origin trust remain external. Tests use explicit synthetic channels and do not prove actual Agent editorial decisions or publication readiness.
