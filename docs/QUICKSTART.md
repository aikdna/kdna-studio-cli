# Quick start

Coordinate scope: this guide targets `@aikdna/kdna-studio-cli@0.13.0`
with Studio Core `4.0.0`. The earlier CLI `0.11.0` belongs to a separate Studio
line. Only the documented session/verify/read commands below are supported here.

Ask a compatible terminal Agent to use `kdna-studio session` with your ordinary `.txt`, `.md` or `.text` material and a new private output directory. Answer the terminal review questions in natural language. The Agent organizes proposals and revisions; Studio creates and binds the final preview.

Follow [the current README](../README.md) and [Agent integration](TERMINAL_AGENT_CREATION.md). Only the documented live blank-material session is supported on this line. Do not use historical project or runtime workflows.
