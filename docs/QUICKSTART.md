# Quick start

Ask a compatible terminal Agent to use `kdna-studio session` with your ordinary `.txt`, `.md` or `.text` material and a new private output directory. Answer the terminal review questions in natural language. The Agent organizes proposals and revisions; Studio creates and binds the final preview.

Follow [the current README](../README.md) and [Agent integration](TERMINAL_AGENT_CREATION.md). Only the documented live blank-material session is supported in this candidate. Do not use historical project or runtime workflows.
